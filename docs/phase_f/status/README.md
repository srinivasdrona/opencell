worktracks. These files are supporting audit records, not live status
authority.

- dated checkpoints: `docs/phase_f/CHECKPOINT_*.md`;
- L2.1 active-window evidence:
  `docs/phase_f/l2_1/L21_ACTIVE_WINDOWS_MANIFEST.json`;
- L2.2 evidence: `docs/phase_f/l2_2_design_a/evidence_index.json`;
- L2.event evidence: `docs/phase_f/l2_event/evidence_index.json`.

Historical or superseded status reports belong in `docs/archive/status/`, not
the repository root.
