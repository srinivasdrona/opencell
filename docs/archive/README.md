(README, plan.md, build config, license metadata).

  full 32,400-tick M. genitalium single-cell-cycle simulation. Superseded

## When to consult

Look here only if you're tracing the history of a specific decision or
referencing a prior investigation's exact wording. Otherwise these are
preserved for audit, not for active reading.
